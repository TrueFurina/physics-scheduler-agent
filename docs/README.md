# 物理实验调课辅助系统

> 物理学科智能排课选课智能体系统 —— 最小闭环版本

一个面向**物理实验教学管理人员**的调课辅助工具：教师说"第六周的课上不了，调到下周"，系统结合**实验安排表 + 学生课表**自动筛选出可用时段，教师选择后由管理员审批。

**核心原则：系统只给分析和建议，不直接修改教务系统。**

---

## 解决的问题

高校物理实验排课存在多重约束：多学院班级、多教师、多实验室、设备资源受限。教师临时调课时，管理人员需要人工核对：
- 该时段教室是否被占用？
- 该班学生是否有其他课程？
- 调课教师自身是否有课？

传统做法靠人肉查表、问学委，效率低且易出错。本系统将这三重冲突检查自动化。

## 功能

| 功能 | 说明 |
|------|------|
| 上传实验安排表 | 支持 .xlsx/.xls，自动解析 434+ 条排课记录 |
| 教师身份选择（F1） | 13 位教师卡片可视化选择，系统知道"用户是谁" |
| 我的课程列表（F2） | 展示当前教师全部课程，区分【可调/不可调】 |
| 模板调课（F3） | 选课程 + 下拉选目标周次，火车票改签式交互 |
| 冲突筛选 + 原因标注（F4） | 教室占用/学生课表/教师冲突三重检查，每个被排除时段附原因 |
| 自然语言调课 | 支持"我是吴琳，第六周的课调到下周" |
| 管理员审批流（F6） | 教师提交申请 → 管理员同意/驳回 → 反馈教师 |

## 快速启动

### 后端

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

> ⚠️ 必须在 `backend/` 目录下启动，`app` 包位于该目录。

### 前端

```bash
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173

## 使用流程

1. 打开前端页面，自动加载默认数据（根目录 `schedule.xlsx`，433+ 条排课记录）
2. **选择教师身份**：点击教师卡片（如"吴琳"）进入其调课工作台
3. **查看我的课程**：展示该教师全部课程，区分【可调/不可调】
4. **模板调课**：选择课程 → 下拉选择目标周次 → 系统自动筛选
5. **查看结果**：绿色可用时段 + 灰色被排除时段（每条附排除原因：教室占用/学生有课/教师冲突）
6. **提交申请**：确认调课申请，状态变为"待审批"
7. **管理员审批**：管理员进入审批台，同意（提示去教务系统修改）或驳回（填原因）
8. 系统反馈教师审批结果

> 也支持自然语言：在对话输入"我是吴琳，第六周的课上不了，调到下周"

## API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/reschedule/upload` | 上传实验安排表 Excel |
| POST | `/api/reschedule/load-default` | 加载默认数据 |
| POST | `/api/reschedule/chat` | 调课咨询（返回可用时段） |
| GET | `/api/reschedule/status` | 系统状态 |
| GET | `/health` | 健康检查 |

## 已知限制

- 学生课表目前内置一份（张敏杰），多学生场景需扩展
- 教师身份识别基于"我是XXX"或姓名关键词，覆盖常见说法
- 仅检查工作日（周一~周五）下午时段，上午/周末不在排课范围
- 演示数据为闽江学院 2024-2025 学年第二学期实验安排表
