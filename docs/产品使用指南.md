# 产品使用指南

**物理学科智能排课选课智能体系统**（Solo 版）· V1.0

---

## 一、产品入口

| 端 | 地址 | 说明 |
|----|------|------|
| Web 前端 | `http://localhost:5173` | 四大模块主界面 |
| API 文档 | `http://localhost:8000/docs` | Swagger 接口文档 |
| 后端服务 | `http://localhost:8000` | FastAPI 服务 |

### 启动方式

```bash
# 后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 前端（另一终端）
cd frontend
npm install
npm run dev
```

> 需要环境变量：`JIYUAN_LVDONG_BASE_URL`、`JIYUAN_LVDONG_API_KEY`（律动基元 LLM 凭据）

## 二、四大模块使用步骤

### 模块 1：排课调课（📅）

**适用**：教师查看课程、调课、查看冲突

1. 打开系统，自动加载实验安排表
2. **选择身份**：点击教师卡片（如"吴琳"）
3. **查看我的课程**：看到该教师全部课程，分【可调 ✅ / 不可调 ❌】
4. **发起调课**：点击课程卡片"申请调课"
5. **选目标周次**：下拉选择（第1-16周），自动筛选
6. **查看结果**：
   - 🟢 可用时段（绿色，可直接选）
   - 🚫 被排除时段（灰色，每条附原因：教室占用/学生有课/教师冲突）
   - 🤖 推荐候选方案（AI 生成 2-3 个，含理由）
7. **提交申请**：确认调课申请，状态变"待审批"
8. **管理员审批**：顶部"⚙️ 审批"入口 → 同意（提示去教务系统修改）/ 驳回（填原因）
9. 审批结果反馈教师

**自然语言调课**：在"💬 自然语言调课"输入框直接说：
- "我是吴琳，第六周的课上不了，调到下周"
- "下周三有点事，把实验课往后挪一周"
- 信息不全时系统自动追问（多轮对话）

### 模块 2：选课咨询（🎓）

**适用**：学生咨询选课资格、先修课程、学分

1. 点击顶部导航"🎓 选课咨询"
2. 输入问题，如：
   - "为什么我选不了大学物理实验课？"
   - "选物理实验需要先修什么课？"
3. 系统基于学生课表，用 LLM 回答（结论 + 原因 + 建议）

### 模块 3：实验辅导（🔬）

**适用**：学生咨询实验原理、数据处理、误差分析

1. 点击顶部导航"🔬 实验辅导"
2. 输入问题，如：
   - "扭摆法测转动惯量的误差来源有哪些？"
   - "如何计算不确定度？"
3. 系统用 LLM 回答（步骤清晰、公式正确、引用实验规范）

### 模块 4：管理员审批（⚙️）

**适用**：管理员审批调课申请

1. 点击顶部导航"⚙️ 审批"
2. 查看待审批申请列表
3. 同意 → 提示"请在教务系统中完成修改"
4. 驳回 → 填写原因反馈教师

### 附加：主数据管理（🗂️）

**适用**：教学秘书 / 实验管理人员维护课程、实验项目、教师、场地、班级

这是导师座谈一号行动项「基于教学大纲梳理实验课程属性、重构数据库」的落地入口。
五张实体表可增删改，排课时随时灵活调取：

1. 点击顶部导航"🗂️ 主数据"
2. 五个 Tab 切换：实验项目 / 教师 / 场地 / 班级 / 课程
3. 首次进入自动从安排表反推；"↺ 从安排表反推"可随时重置回基线（撤销本会话增删改）
4. 增删改需管理员登录（顶部"⚙️ 审批"输入口令后回来即可），未登录为只读
5. **新增实验项目**：填名称、所属课程、可授课教师、可用场地、适用班级 →
   该项目自动进入对应班级的「并行排课」待排清单，一键排定，不必伪造旧课表行
6. **班级的上课时间范围**（星期 / 节次 / 周次）：教务教学管理人员已经分配好的「课程总时间范围」，
   并行排课只在这个范围内排实验（不会排到范围外的星期/节次/周次）。反推自安排表，可手动改
7. **灰箱排课（信息不全也能一键排）**：清单/主数据里缺什么（教师、场地、星期、节次、周次），
   系统按已有信息自动补全并排课——缺的教师从主数据该项目的可授教师里分配（多人时自动均摊负载），
   没给星期就按历史最常用，节次/周次没给就用默认范围。**系统替你做的每个决定都会列在
   排课结果的「🧩 灰箱补全」说明里**，不认可就到主数据里改掉再重排；完全没信息的项目会如实标注
   「教师列为空」，绝不静默留空
8. **数据持久化**：主数据的增删改和上传的清单**自动落盘**，重启（含线上沙箱回收）后自动恢复，
   不用重录；换新的安排表上传后，旧表上的修改自动作废（新表的班级/项目可能已不存在）

## 三、数据说明

| 数据 | 来源 | 更新方式 |
|------|------|---------|
| 实验安排表 | 闽江大学 24-25 学期 | 上传 Excel 可替换（支持其他学校，见下方"换学校数据"） |
| 教学大纲 / 项目清单 | 可选 | 上传「实验项目清单」，作为**从零排课**的输入（没排过时间的项目也能一键排定） |
| 学生课表 | 内置张敏杰课表 | 上传 Excel/PDF 可替换 |
| 调课申请 | 运行内存 | 重启后清空（演示用） |

**时间段说明**：

| 节次标记 | 实际时间 |
|---------|---------|
| 567 | 13:30-15:45 |
| 678 | 15:45-18:00 |
| 91011 | 18:30-20:45 |
| 78 | 15:50-18:05 |

**换学校数据（怎么把另一所学校的表喂进来）**：

1. 安排表放在任意一个名为「实验安排表」（或含"安排表"二字）的工作表里，列顺序为
   `周次 / 星期 / 时段 / 班级 / 学生组 / 实验项目 / 场地 / 教师`（前两行可为标题与表头）。
2. **没排时间的行不再被丢弃**：表里只要写了「班级 + 实验项目」但没填周次/星期，
   系统会把它记为**待排任务**（上传后会明确告诉你"另有 N 条待排"），可直接进「并行排课」一键排定
   —— 这正是"从零排课"：今年大纲里新增的实验项目，不必先伪造一行旧课表。
3. 也可以单独上传一份「实验项目清单」（列：课程 / 班级 / 实验项目 / 学生组 / 教师 / 场地），
   系统按表头识别列名，这些项目会直接进入并行排课的总览与求解。

## 四、注意事项

1. **必须先在 backend 目录启动后端**（`app` 包在该目录下）
2. **LLM 服务不稳定时**：核心流程（排课/调课筛选）由规则引擎兜底，不依赖 LLM 也能用
3. **身份选择替代登录**：演示用可视化选择，无需账号密码
4. **换学校数据**：上传该校实验安排表 + 学生课表即可，系统自动解析；表名/列名不严苛匹配
5. **系统不改教务系统**：审批通过后由管理员人工在教务系统修改

## 五、适用场景

- 教师临时有事需调换实验课时间
- 管理员评估调课可行性（多班多教室冲突）
- 学生选课资格咨询（先修课/学分）
- 学生实验辅导（原理/数据处理/误差分析）
- 高校实验教学中心日常排课管理
- **全校一键自动排课**：171 个教学任务分片求解（约 15–25 秒）全部排定，
  避开现有安排表的教室/教师/班级占用，结果可导出「总表 + 每班一页」Excel

## 六、不适用场景

- ❌ 需要学生个人课表参与判定的「个别学生轻微冲突」（学生课表涉及 PII，未接前端）
- ❌ 移动端（仅 Web）
- ❌ 教务系统双向对接（需学校接口支持）
